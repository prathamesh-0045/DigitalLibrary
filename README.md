Digital Library Management System

Full-stack library management application using **React.js + Vite**, **Spring Boot REST API**, and **MySQL**.

Features: Login/Register, Admin Dashboard, Add/Edit/Delete Books, Borrow/Return, Reservations, Automatic Fines, My Shelf, Search, Genre Filtering, and Contact.

See `ARCHITECTURE.md` for the project architecture and `RUN_GUIDE.md` for setup.
