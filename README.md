# 📚 Digital Library Management System

A modern full-stack Digital Library Management System built with **React.js + Vite**, **Spring Boot REST API**, and **MySQL**.

The application provides a clean and attractive interface for managing books, borrowing and returning books, reservations, users, and automatic overdue fines.

---

## 🚀 Features

### 👤 User Features

- User Registration
- User Login
- Browse available books
- Search books by title, author, or ISBN
- Filter books by genre
- Borrow books
- Return books
- Reserve unavailable books
- View borrowed books in **My Shelf**
- View due dates
- Automatic overdue fine calculation
- Contact library support

### 🛡️ Admin Features

- Admin Dashboard
- Add new books
- Edit book information
- Delete books
- View total books
- View members
- View active loans
- View reservations
- Manage library catalogue
